### Verification notes for Code / TJ (read before embedding)

All four URLs are real Wikimedia Commons pages that consistently resolve across independent searches and third-party public-domain mirrors (PICRYL, Creazilla), and all are period-correct Sidney Paget Strand Magazine illustrations (1890s), which are unambiguously public domain. That said, my research pass could not directly fetch commons.wikimedia.org to read the license tag or confirm the exact scene depicted on two of the four — flagging so Code can do a quick one-click check before the images ship publicly:

1. **Sherlock Holmes (Paget_holmes.png)** — well-established as the standard reference Paget portrait of Holmes (used on Wikipedia's own Holmes article). High confidence, but I didn't confirm which specific story it's drawn from.
2. **John Watson** — this file is actually a two-character illustration (Holmes *and* Watson together) from "The Adventure of the Greek Interpreter." It works fine as Watson's image, but if Code wants a cleaner Watson solo shot, it's worth a quick search on Commons' Category:Sidney Paget illustrations for one.
3. **Reichenbach Falls** — strongly confirmed. This exact file is also mirrored on English Wikipedia's own File namespace and appears in a PICRYL collection explicitly tagged "Illustrations from 'The Adventure of the Final Problem' by Sidney Paget... free for commercial use, no attribution required." Highest-confidence image of the four.
4. **A Scandal in Bohemia scene** — this is file #4 in a sequential set of ten Paget illustrations Commons hosts for the story (Category:A_Scandal_in_Bohemia). I could not confirm exactly which moment in the story it depicts — likely the King of Bohemia or a disguise scene rather than Irene Adler herself, since scholarly sources note Adler wasn't directly illustrated in the original Strand run. Recommend a quick visual check, or Code can browse the full Category:A_Scandal_in_Bohemia set on Commons and pick whichever frame reads best.

If any of these don't check out on inspection, the whole Category:Sidney Paget illustrations tree on Wikimedia Commons is a reliable place to pick a substitute — every image in it is the same vintage and PD status.
